# Webpack/Babel — Course Reference

A link-oriented exercise from the [WebDev course](../../../../../README.md) pointing to the instructor's separate [Webpack/Babel starter project](https://github.com/AndrewSouthpaw/webpack-babel-starter-project).

**This directory is not a standalone application.** It does not ship a complete Webpack/Babel package manifest, executable build script or dataset. To follow the exercise, inspect the linked upstream repository, clone it separately, and use its own installation commands and dependency versions. Do not run `npm install` in this directory and expect a runnable demo.

No external data procurement, service credentials, screenshot or deployment is supplied here.
